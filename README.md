# Phoen1x.kg — сайты для заведений и NFC-таблички

Статический одностраничный сайт. Услуги: сайты для ресторанов, кафе и кофеен + дизайн NFC-табличек трёх видов. Кассы, заказы, оплата и интеграции **не** входят в концепцию.

## Запуск

Откройте `index.html` в браузере — сборка не нужна. Для локального сервера:

```bash
npx serve .
```

## Что проверить перед публикацией

1. Цены тарифов и табличек — подтвердить финальные значения.
2. Блок `#cases` — примеры правдоподобные, замените на реальные кейсы.
3. Политика конфиденциальности — готова на `privacy.html`, ссылки добавлены в форму, футер и мобильное меню. Перед публикацией проверьте текст под ваши процессы и замените ссылку `index.html` на реальный адрес сайта.

## Структура

- `index.html` — разметка, инлайн-SVG иконки, демо-телефон
- `privacy.html` — политика конфиденциальности
- `styles.css` — палитра, типографика, адаптив, анимации
- `script.js` — мобильное меню, демо, калькулятор, форма заявки

## Дизайн

Палитра: чёрно-зелёный базис `#07110D`, глубокий зелёный `#0D1D15`, акцент `#34C77B`, светло-мята `#B9F2CD`, тёплый крем `#E5DFCF`.
Шрифты: Unbounded (заголовки) + Golos Text (текст), обе с кириллицей.

Центральный визуальный элемент — интерактивный телефон с тремя состояниями: касание таблички, меню, сайт. Кнопки под ним и клик по телефону переключают экраны.

Все ключевые числа (цены тарифов и табличек, цифры в первом экране, сумма калькулятора) работают как одометр: прокручиваются при входе в видимую область и повторяют прокрутку при движении вверх или вниз. Анимация отключается при `prefers-reduced-motion`.

## Доступность

- Видимый фокус с клавиатуры, `aria-*` для мобильного меню и демо
- Уважается `prefers-reduced-motion`
- Адаптив от 320 px, проверка пустых полей формы
